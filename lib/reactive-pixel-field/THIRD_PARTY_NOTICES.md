Reactive Pixel Field has no third-party runtime dependencies and loads no image media. The JavaScript, CSS, demo content, palette configuration, and rendering logic in this package are NT-owned implementation source.

The optional React/Next.js adapter imports React from the consuming host. React is not bundled with this Component and remains subject to the version and license selected by that host. The repository's isolated reference project declares the exact React and Next.js versions used for compatibility verification.
